# Infinia Creative Studio — releases

Official desktop installers, checksums, and release metadata for
**Infinia Creative Studio**, an Infinia Labs product.

Infinia Creative Studio is one desktop suite for authoring and document work:
Docs (.docx), Sheets (.xlsx), Slides (.pptx), PDF, plus new **Markdown** and
**HTML** editors, with the Infinia Studio (AgenticOCR) document-AI service for
OCR, conversion and generation.

## Verify a download

Every release attaches a manifest (`release.json`) and a `SHA256SUMS` file.
Download the installer and the manifest, then compare:

```bash
shasum -a 256 InfiniaCreativeStudio-0.6.0-arm64.dmg
# or, on Linux:
sha256sum InfiniaCreativeStudio-0.6.0-arm64.dmg
```

The printed digest must match the entry in `SHA256SUMS` and the `sha256`
field for that asset in `release.json`. Checksums verify that a download
matches the published file; they are not a code-signing or notarization claim.

## Release status

macOS packages are ad-hoc signed and **not Apple-notarized**. On first launch,
open the app with **right-click → Open**, or clear the quarantine flag:

```bash
xattr -d com.apple.quarantine "/Applications/Infinia Creative Studio.app"
```

Windows installers are unsigned. SmartScreen may ask you to confirm the
publisher before the installer runs.

Use only the assets attached to a specific release. Downloading from any other
source is unsupported.

## Release metadata

`release.json` is the machine-readable manifest the product site and the
in-app updater consume. Keep versioned assets immutable: never replace the file
behind a published name. To publish a new version, attach the new assets, bump
`release.json`, `SHA256SUMS` and `CHANGELOG.md`, and cut a new tag.

The updater feed (`latest.yml` / `latest-mac.yml`) is generated by
electron-builder during a release build and hosted on the product site. This
repository is the human-facing index and the canonical checksum source.
